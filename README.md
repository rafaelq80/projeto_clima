# 🌤️ Previsão do Tempo



Aplicação web simples que exibe a **previsão do tempo em tempo real**, utilizando as **APIs Open-Meteo** (Geocoding e Weather). Desenvolvida com **HTML, CSS e JavaScript puro**, oferece uma interface amigável, responsiva e dinâmica, que alterna automaticamente entre **modo diurno e noturno**.

---

## 🚀 Como Executar a Aplicação

1. **Baixe ou clone o repositório:**

   ```bash
   git clone https://github.com/rafaelq80/previsao-do-tempo.git
   ```
2. **Estrutura de diretórios esperada:**

   ```
   /assets
     /css/styles.css
     /js/api.js
     /images/
   /tests/api.test.js
   index.html
   ```
3. **Abra o arquivo `index.html`** diretamente no navegador.
   Nenhum servidor é necessário — a aplicação roda totalmente no cliente.
4. Se preferir, abra no Visual Studio Code e execute a aplicação utilizando a extensão **Live Server**

---

## 🧠 Como Executar os Testes com Jest

1. **Instale o Jest** como dependência de desenvolvimento:

   ```bash
   npm install --save-dev jest
   ```

2. **Execute os testes:**

   ```bash
   npm test
   ```

---

## 🧩 Tecnologias Utilizadas

* **HTML5** – estrutura da aplicação
* **CSS** – estilização e responsividade
* **JavaScript (ES6+)** – lógica e consumo das APIs
* **Open-Meteo API** – dados meteorológicos em tempo real
* **Jest** – testes automatizados
